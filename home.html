Web Technology Highlights

This project demonstrates fundamental Client-Server principles of web architecture:

  • Client-Side Rendering: HTML4 Framesets create multi-pane layouts while Image Maps handle spatial navigation click events.
  • Server-Side Processing: PHP processes HTTP POST inputs, manages persistent session state across page refreshes, and updates server file storage.
  • Separation of Concerns: Styling is encapsulated within standard CSS (`style.css`), keeping structural markup clean.
